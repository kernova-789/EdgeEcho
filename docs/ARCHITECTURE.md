# 核心与数据流

桌面程序和 CLI 共用 `edgeecho_core`。Qt 是可选前端；核心仅依赖 C++17 和本地 SQLite。原 EdgeSense Replay 只参与单独的兼容验证，不是运行依赖。

```text
离线 replay.db
    │ URI immutable + read-only，身份/版本/sidecar/变更检查
    ▼
Database ── overview ── 系列(sensor,type,unit)
    ├── page ── 原始 Record ── 表格 / 无损 CSV
    ├── events ── 按id最新revision，再过滤区间/撤销 ── 诊断背景/表格
    └── plot ── decode ── 有界时间桶min/max ── QPainter
                         ▲
                    质量中断 / 取消 / 预算

steady_clock → PlaybackClock → 当前 UTC 位置 → 游标 / 越界请求下一窗口
```

## 读取约束

输入契约是停止写入并关闭连接后的离线库或一致备份。`immutable=1` 避免读取在源目录创建 WAL/SHM；不是活动库的读取方式。非空 WAL 和回滚日志均拒绝。文件大小/mtime 检查只用于发现误用，不能替代这个契约。应用无需更改 schema 或索引。

Database 每实例只在一个线程使用。它持有只读事务和记录高水位，页面按 `(ts,seq)` 键集排序。时间字段以64位微秒存储，计算范围限制在1970..9999年；绘图时先整数减去窗口起点，之后才转浮点。

普通页给 SQLite 显式 `ts >= max(start,cursor.ts)` 下界，元组条件排除同刻已读序号，避免深页重新扫描早期历史。曲线用 v3 的 `records_coverage_end` 查询跨入左边界的好质量 BLOB，再用时间索引扫描窗口内记录；不把 OR 条件变成全历史遍历。

每条先获取编码大小，BLOB 的 CASE 分支在超过单条预算时不复制数据。页面条数满时不提前拒绝下一条的大载荷；下一页才判单条预算。页总字节不足会在已读数据之后给出续页，首条即超预算则明确报错。事件有独立条数和同样严格的累计字节限制。

## 绘图语义

`decode` 只理解明确列出的编码；原始载荷不会被降采样结果替换。无 rate 的特征scan使用记录时间；波形使用名义采样率重建，保持估计时间标识。未知编码、截断、无 rate 或时间超出 duration 会报错，原始记录仍可查看和导出。

`plot` 跳过非零质量并输出断点，时间桶记录两极值及其真实时间。正常数据输出约2×桶数，中断增加少量边界点；预算超限不返回成功的部分曲线。波形之间有覆盖间隙或重叠时断开；标量/特征没有采集计划，不凭时间间隔擅自推断丢采样。

## 界面并发

QtConcurrent 工作线程创建并销毁 Database；GUI线程接收有限 Plot/Page/Event 值对象。最多一项任务运行，另保留最新待执行请求；新请求取消旧请求并通过 generation 排除过期结果。关闭窗口取消任务并等待工作完成。SQLite progress handler、解码及逐记录循环都检查取消/时限。

PlaybackClock 管理时间位置，不负责投递每条原始记录。暂停不推进，seek 清除小数余量，倍速保留不足1微秒的累计，达到末尾可重新播放。完整原始输出由 page/export 提供。

## 后续扩展

如果需要在线采集期间回放，应另设计一致快照的生成与切换流程，不能直接去掉 WAL 检查。音频设备输出、FFT、多系列对齐、物理量换算也应分别增加明确输入契约和验收，不能由现有原始 count 或主机时间推断。

## 0.3 浏览与构建基线

`Database::plots` 对一个完整系列扫描一次SQLite记录，再对请求通道流式解码；记录预算按实际行计算，解码预算按所有通道值合并计算。每个时间桶仍保留极值及其时间，全部输出点共享字节预算。`plot`委托给单通道`plots`，避免语义漂移。

`Database::probe`独立读取可见区间的原始记录，跳过缺失、非好质量和非有限值，以距离目标时间最近的样本为结果，等距离优先较早时刻，同刻保留稳定记录顺序。它不会查询屏幕包络，也不插值。重建采样时刻仍受rate/duration约束，不能自动变成传感器真实时钟。

主窗口保留最多3个/估计32MiB结果缓存；键含SourceIdentity、完整系列、通道、半开区间和分辨率。缓存命中前后构造只读Database核对身份。预取与悬停为低优先任务，前台请求使其取消/过期。最后一个窗口使用与前台seek完全相同的`windowAt`计算，避免尾端预取键不匹配。缓存预算不等于进程RSS硬限制。

图表交互由`app/plot_widget.*`处理，变更范围后通过回调发起新查询。日历及夏令时判定由`app/time_range_editor.*`处理；UTC微秒是唯一查询时间，日历毫秒和微秒余数仅作为编辑方式。最大结束边界显示其前1微秒但不改变规范区间。

记录表采用批量更新、交互列宽和32行抽样测量；不在每次setItem后对全部512行执行ResizeToContents，避免在界面线程出现重复字体布局。

统一源码身份覆盖核心、界面、测试、构建工具和工作流。`tools/validate_current.py`为每次运行创建独立JUnit位置，核对刚配置的测试清单并拒绝空/跳过/旧结果及源变化。GUI、CLI、Linux包和Windows交叉产物绑定同一源码标识。运行证据的范围由profile单独说明，不能以交叉构建代替原生运行。
