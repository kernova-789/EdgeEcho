## EdgeEcho 0.6.0

此版本将桌面端和命令行统一接入 EdgeSense Replay 1.2 Core，可打开已关闭写入的 Replay v3 数据库和正式备份中的 `replay.db`。

- 历史曲线、精确探针、音频和频谱共用 Replay 的窗口分页和信号解码，支持 XYZ 48 字节和 XYZS 72 字节特征扫描。
- 诊断时间线读取当前有效事件版本和确认状态。原始记录表及 CSV 保留记录顺序、原始载荷和元数据字节。
- 演示库由 Replay 写入接口生成。源码构建可使用 Replay 1.2 Core 安装包或本地源码目录。

## Linux x86‑64 下载与运行

下载 `EdgeEcho-0.6.0-linux-x86_64.tar.gz` 及同名 `.sha256` 校验文件，在下载目录执行以下命令。

```bash
sha256sum -c EdgeEcho-0.6.0-linux-x86_64.tar.gz.sha256
tar -xzf EdgeEcho-0.6.0-linux-x86_64.tar.gz
cd EdgeEcho-0.6.0-linux-x86_64
./edgeecho
```

也可运行 `./edgeecho /path/to/replay.db` 打开离线库，或用 `./edgeecho_cli --help` 查看命令。发行包包含 Qt 运行库和平台插件，桌面使用需要兼容的 Linux 系统 ABI 和图形环境。包内 `PACKAGE.json` 记录构建所用的 glibc 版本。

## 验证

Linux 桌面版通过 13 项测试，ASan/UBSan 通过 9 项测试，并验证了 Replay 写入的跨页样例、已有 v3 备份和发行包的异路径运行。旧版库的大窗口读取经批量分页优化后仍有额外开销。
